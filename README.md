# AFL Manager V7

V7 focuses on the football simulation itself:
- Possession/event based live match layer
- Match clock, quarters, scores and momentum
- Player fatigue, confidence and time-on-ground foundations
- Interchange/rest controls
- Individual player instructions
- Training focus and training load
- Player demands and responses
- Awards/history records
- Rivalry tracking foundation
- Persistent V7 save namespace

This is a browser prototype. Upload `index.html` to GitHub Pages and use `?v=7` if an older cached page appears.
